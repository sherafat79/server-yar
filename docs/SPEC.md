# ServerYar (سرور یار) — مشخصات

پنل وب شخصی برای مدیریت سرورها، سرویس‌ها، دامنه‌ها، هزینه‌ها و تمدیدها، با مانیتورینگ آپ‌تایم و نوتیف تلگرام.

## معماری
- Monorepo با pnpm:
  - `apps/server` — Hono + Drizzle + SQLite (better-sqlite3) + grammY + croner
  - `apps/web` — Vite + React + TS + Tailwind v4 + shadcn/ui (RTL) + Motion + Recharts + TanStack Query، PWA
  - `packages/shared` — تایپ‌ها و اسکیمای Zod مشترک
- بکند SPA را هم سرو می‌کند → یک کانتینر.
- دیپلوی: Docker Compose + Caddy (HTTPS خودکار) روی سرور خارج. بکاپ روزانهٔ دیتابیس به تلگرام.

## کاربران و امنیت
- نقش‌ها: `admin` (همه‌چیز، مدیریت کاربران/تنظیمات، دیدن رمزها) و `member` (دیدن/ویرایش؛ دیدن رمز پیش‌فرض بسته، از تنظیمات قابل‌باز شدن).
- لاگین: یوزرنیم + پسورد (scrypt) + TOTP (اپ Authenticator، راه‌اندازی با QR).
- سشن با کوکی httpOnly، عمر ۷ روز. ۵ تلاش ناموفق → ۱۵ دقیقه قفل.
- ادمین اولیه با دستور CLI ساخته می‌شود؛ صفحهٔ ثبت‌نام عمومی وجود ندارد.
- رمزها با AES-256-GCM و کلید `ENCRYPTION_KEY` در `.env`. گم شدن کلید = غیرقابل‌بازیابی بودن رمزها.
- نمایش رمز: نیاز به کد ۲FA تازه، نمایش ۳۰ ثانیه، دکمهٔ کپی، ثبت در لاگ (بدون نوتیف تلگرام).
- لاگ فعالیت: چه کسی چه چیزی را تغییر داد.

## داده‌ها
- **سرور**: نام، چند IP، پروایدر، فروشنده، لوکیشن، سیستم‌عامل، CPU/RAM/دیسک/ترافیک، لینک پنل، SSH و لاگین پنل (رمزنگاری‌شده)، قیمت، ارز (IRT/TRY/USD)، دوره (ماهانه/سه‌ماهه/شش‌ماهه/سالانه)، سررسید بعدی، تمدید خودکار، تگ، یادداشت، وضعیت فعال/بایگانی، حالت تعمیرات.
- **سرویس**: نام، نوع (ربات تلگرام / وب‌سایت / API / دیتابیس / Cron-Worker / پنل / سایر)، سرور، دامنه (اختیاری)، پورت، روش چک، URL چک، کلمهٔ کلیدی، مسیر/کانتینر، تگ، یادداشت، حالت تعمیرات.
- **دامنه**: نام، رجیسترار، انقضا، هزینه + ارز، تمدید خودکار، یادداشت.
- **پروایدر** و **فروشنده**: دو لیست قابل‌مدیریت.
- **پرداخت‌ها**: تاریخچهٔ هر تمدید. دکمهٔ «تمدید شد» سررسید را یک دوره جلو می‌برد و پرداخت را ثبت می‌کند.
- هزینه‌ها برای هر ارز جدا جمع زده می‌شوند (بدون تبدیل).

## مانیتورینگ (بدون Agent)
| هدف | روش |
| --- | --- |
| سرور | ping (ICMP) + TCP روی پورت SSH |
| وب‌سایت/API/پنل | HTTP(S): status code + کلمهٔ کلیدی اختیاری |
| دیتابیس/پورت | TCP |
| ربات تلگرام/Cron | Heartbeat: سرویس `GET/POST /hb/<token>` را صدا می‌زند |

- چک‌ها هر ۶۰ ثانیه. دادهٔ خام ۳۰ روز، بعد میانگین ساعتی.
- SSL و whois دامنه روزی یک بار.
- هشدار داون بعد از ۲ چک ناموفق متوالی. حالت تعمیرات هشدار را قطع می‌کند و در آپ‌تایم حساب نمی‌شود.

## تلگرام
- نوتیف‌ها در کانال پست می‌شوند:
  - تمدید سرور/دامنه: ۷، ۳، ۱ روز قبل و روز سررسید، ساعت ۱۰ صبح تهران
  - داون/آپ شدن
  - انقضای SSL (۱۴، ۷، ۳، ۱ روز قبل)
  - بکاپ روزانهٔ دیتابیس
- دستورهای فقط‌خواندنی (`/status`، `/servers`، `/renewals`) فقط در پیوی و فقط برای chat_idهای وصل‌شده. اتصال از پروفایل کاربر با لینک `t.me/<bot>?start=<code>`.

## UI
- فارسی، راست‌چین، فونت Vazirmatn. تاریخ شمسی + میلادی کوچک زیرش.
- تم شیشه‌ای تیره پیش‌فرض + سوییچ به روشن.
- صفحه‌ها: داشبورد، سرورها، سرویس‌ها، دامنه‌ها، تمدیدها، هزینه‌ها، رخدادها و لاگ، تنظیمات.
- داشبورد (الگوی F): KPIها (سرورهای آنلاین، سرویس‌های داون، تمدیدهای ۳۰ روز آینده، هزینهٔ ماهانه به تفکیک ارز) → تایم‌لاین تمدید ۶۰ روزه + وضعیت زندهٔ سرویس‌ها → آپ‌تایم ۷ روزه، هزینه به تفکیک پروایدر، آخرین رخدادها.
